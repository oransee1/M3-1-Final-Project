2026.10.19. 제작
Suno Command Maker 에서 설정한 값 적용

기본 설정:
- 분류: 싱글곡
- 곡 형태: 가사곡
- 곡의 용도: 노래
- 주제: Forever Starts Tonight
- 장르: 발라드 + 락
- 곡 제목: 랜덤. 챗봇이 곡마다 적절히 설정
- 곡 후킹가사: 랜덤. 챗봇이 곡마다 강한 훅을 직접 설계
- 곡 추임: 랜덤. 챗봇이 장르와 보컬에 맞게 ad-lib/추임새를 설계
- 길이: 4분
- BPM: 직접 지정하지 않음. 곡의 용도, 장르, 강도, 분위기를 바탕으로 챗봇이 적절히 설정
- 곡 강도: 강함
- 분위기: 감성적
- 곡 구성: 인트로-벌스-프리코러스-후렴-브릿지-마지막 후렴
- 곡 형태: 가사곡
- 보컬: 듀엣
- 언어: 영어
- 가사 밀도: medium
- 훅 강조: 중간
- 라임/반복: 자연스러운 라임
- 피하고 싶은 요소: 없음
- 스타일 프롬프트 언어: 영어

패키지 생성 지시:
1개의 싱글곡 후보를 하나의 패키지로 생성한다.
모든 후보는 같은 제목, 같은 훅, 같은 핵심 편곡 방향을 공유하는 같은 곡의 여러 버전이다.
후보마다 완성도, 표현 방식, 세부 질감만 미세하게 다르게 만들어 사용자가 가장 좋은 버전을 고를 수 있게 한다.
- 구체적인 결과물의 차별화 방향은 챗봇이 음악적 완성도를 기준으로 판단한다.
- 같은 패키지 안에서 서로 비슷한 결과는 피한다.

가사/구조 지시:
가사곡으로 작성한다.
가사 밀도는 중간. 벌스와 후렴의 균형을 맞추고 바로 노래로 만들 수 있는 완성형으로 작성.
가사 언어는 영어 중심으로 작성한다.
보컬은 듀엣 설정에 맞춰 파트와 음역을 배치한다.
Suno에 붙여넣기 좋게 [Verse], [Pre-Chorus], [Chorus], [Bridge], [Outro] 섹션 태그를 사용한다.
곡 길이에 맞게 8개 섹션으로 나누고, 챗봇이 정한 BPM에 맞춰 마디 수를 함께 명시 기준으로 가사량을 조절한다.

곡 길이 맞춤 지시:
목표 곡 길이는 4분이다.
챗봇이 곡의 용도, 장르, 강도, 분위기에 맞춰 정한 BPM을 기준으로 전체 마디 수와 섹션별 마디 수를 계산한다.
Verse, Pre-Chorus, Chorus, Bridge, Outro의 섹션 수와 각 섹션의 가사 줄 수를 조절해서 실제 Suno 결과가 목표 길이에 최대한 근접하도록 작성한다.
곡 길이에 비해 가사가 너무 길거나 짧아지지 않도록 반복 후렴, 짧은 브리지, 아웃트로 길이를 함께 조절한다.

품질 지시:
- Style Prompt는 Suno가 이해하기 쉬운 음악 제작 키워드 중심으로 작성하고, 설명은 한국어로 붙여줘.
- 스타일 프롬프트 언어가 영어이면 Style Prompt 내용은 영어로 작성해줘.
- 스타일 프롬프트 언어가 한국어이면 Style Prompt 내용은 한국어로 작성해줘.
- 장르명이 여러 개인 경우 억지로 나열하지 말고 실제로 섞인 사운드가 떠오르게 작성해줘.
- 곡의 용도에 맞게 에너지, 반복성, 보컬 존재감, 믹스 공간을 조절해줘.
- 결과는 복사해서 바로 사용할 수 있게 군더더기 없이 작성해줘.
